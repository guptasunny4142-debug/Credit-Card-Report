Project Overview
=========================================================================================================================================
This project focuses on analyzing credit card transaction data using Microsoft Power BI. The objective is to understand customer spending behavior, revenue generation, interest earned, and transaction patterns across different demographic and customer segments.

The dashboard provides an interactive view of key business metrics and enables analysis based on customer job, income group, age, education, marital status, dependent count, state, card category, and transaction method.

* Revenue: **55.3M**                                                                                                                                                             
* Total Interest Earned: **7.84M**                                                                                                                                                    
* Transaction Amount: **45M**                                                                                                                                                     
* CSS: **3.19**

Business Problem
===========================================================================
1. Which customer segments generate the highest revenue?
2. Which occupations contribute most to revenue and interest earned?
3. How does revenue vary across different income groups?
4. Which age groups generate the most revenue?
5. Which states contribute the highest revenue?
6. How does revenue change over time?
7. Which card categories generate the most revenue?
8. How does transaction behavior differ between Swipe, Online, and Chip transactions?
9. Does customer education level influence revenue?
10. How does revenue vary by marital status and dependent count?
